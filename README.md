# IoT Home Security System

## About the Project
This is a student project that demonstrates a basic home security system using electronic components and giving alert on phone through IoT system

## Components Used
- Microcontroller: NodeMCU ESP8266
- Sensors: PIR Motion sensor
- LED
- Buzzer
##Software used
- arduino ide
- BLYNK cloud
- BLYNK IOT

## Working Principle
The system monitors sensor inputs. When the programmed condition is detected, the LED turns on and the buzzer sounds as an alert. after that through BLYNK we get a notification alert on our phones

## Project Features
- LED indication
- Buzzer alert
- Sensor-based detection
- wireless notification
- notification alert
